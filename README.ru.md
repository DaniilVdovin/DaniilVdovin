Внутренние инструменты для команды: общие библиотеки компонентов, шаблоны, навыки для агентов, MCP-инструменты.
Внедряю ИИ-агентов в цикл разработки: оркестрация задач, code review, документация.

- 🎓 4+ года автоматизации рабочих процессов вуза параллельно (РУДН, Сочинский филиал)
